# What is TypeScript?

TypeScript is a **statically typed superset of JavaScript** developed by **Microsoft**.

* Every valid JavaScript program is also valid TypeScript.
* TypeScript adds **static typing** and other advanced features on top of JavaScript.
* TypeScript code is compiled into JavaScript before execution.

---

# Why was TypeScript Created?

JavaScript works well for small projects, but as applications grow:

* Runtime bugs become difficult to identify.
* Code becomes harder to maintain.
* Large teams require better code safety.

TypeScript solves these problems by introducing:

* Static type checking
* Better tooling
* Improved maintainability
* Safer refactoring
* Better developer experience

# JavaScript vs TypeScript

| JavaScript                | TypeScript                      |
| ------------------------- | ------------------------------- |
| Dynamically Typed         | Statically Typed                |
| Errors found at Runtime   | Errors found during Compilation |
| Less Safe                 | More Safe                       |
| Better for Small Projects | Better for Large Projects       |

# Important Terminologies

## 1. TypeScript

A statically typed superset of JavaScript.

---

## 2. Superset

A language that contains all the features of another language plus additional features.

Example:

```text
JavaScript ⊂ TypeScript
```

---

## 3. Compiler

A program that converts TypeScript code into JavaScript.

The TypeScript compiler also checks for type-related errors before generating JavaScript.

---

## 4. Static Type Checking

TypeScript checks variable types during compilation instead of waiting until runtime.

Example:

```ts
let age: number = 20;

age = "Twenty"; // Error
```

# Interview Questions

## Q1. What is TypeScript?

**Answer:**

TypeScript is a statically typed superset of JavaScript developed by Microsoft that compiles into JavaScript.

---

## Q2. Why was TypeScript created?

**Answer:**

To overcome JavaScript's limitations in large applications by adding static typing, better tooling, and improved maintainability.

---

## Q3. What does "TypeScript is a superset of JavaScript" mean?

**Answer:**

Every valid JavaScript program is also a valid TypeScript program because JavaScript is a subset of TypeScript.

---

## Q4. Can browsers execute TypeScript directly?

**Answer:**

No.

Browsers only understand JavaScript.

TypeScript must first be compiled into JavaScript.

---

## Q5. What does the TypeScript compiler do?

**Answer:**

* Checks for type errors
* Converts TypeScript into JavaScript

---

## Q6. Who developed TypeScript?

**Answer:**

Microsoft.

---

## Q7. Why do companies use TypeScript?

**Answer:**

* Static type checking
* Better maintainability
* Improved developer experience
* Easier debugging
* Better scalability

# Key Takeaways

* TypeScript is **not** a replacement for JavaScript.
* TypeScript extends JavaScript.
* Browsers execute JavaScript, not TypeScript.
* The TypeScript compiler converts TypeScript into JavaScript.
* TypeScript helps developers catch errors before the application runs.
* Most modern React applications use **React + TypeScript**.

---

# Common Beginner Mistakes

❌ Thinking TypeScript is a completely different programming language.

✔️ TypeScript is JavaScript with additional features.

---

❌ Thinking browsers execute TypeScript.

✔️ Browsers execute JavaScript generated by the TypeScript compiler.

---

❌ Thinking TypeScript replaces React.

✔️ TypeScript works together with React.
