ML learns patterns automatically from data.

5. WHAT IS AN LLM?

LLM = Large Language Model

Examples:

OpenAI models
Google Gemini
Anthropic Claude
Meta Llama

LLMs are trained on:

books
websites
code
articles
conversations

Goal:

predict the next token(word piece).

MOST IMPORTANT CONCEPT

ChatGPT does NOT “think” like humans.

It predicts:

“What token should come next?”

Example:

Input:

India is my favorite ___

LLM predicts:

country

Very advanced token prediction = powerful AI behavior.

WHAT ARE TOKENS?

Tokens are pieces of text.

Example:

Sentence:

I love coding

Possible tokens:

["I", "love", "coding"]

Sometimes tokens are partial words too.

LLMs process:

tokens
NOT full sentences.
NOTE THIS
LLM Definition

An LLM is a deep learning model trained on massive text data to understand and generate human-like language.

Important Point

LLMs work using token prediction.

6. HOW CHATGPT WORKS (CONCEPTUALLY)

VERY IMPORTANT.

This is commonly asked in interviews.

Flow:

User Input
   ↓
Text converted into tokens
   ↓
LLM processes tokens
   ↓
Predicts next token repeatedly
   ↓
Generates final response

That’s the simplified version.

WHAT MAKES CHATGPT POWERFUL?

Three major things:

Huge training data
Huge neural network
Transformer architecture

You don’t need deep transformer math currently.

Only understand:

transformers help models understand context efficiently.

Example:

8k

Larger context:
→ better memory.

Temperature

Controls randomness.

focused
factual

High temperature:

creative

Example:
